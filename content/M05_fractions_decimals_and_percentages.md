# M05 — Fractions decimals and percentages

**Status: Draft — awaiting review. Not approved for PowerPoint.**

## Scope

Equivalence and comparison. Simplify fractions, convert between forms, and compare values. Fraction arithmetic is not included.

Challenge progression: familiar equivalents → less familiar values → compare mixed forms.

Calculator proposal: no calculator; repeating decimal notation appears only in the worked teacher explanation of 2/3.

## Row labels and practice prompts

Use these exact labels and prompts on both step-by-step practice slides. Repeat the same prompt across columns unless a genuine difference in the task requires a change.

| Row label | Student prompt |
| --- | --- |
| Identify the Value | Identify the given form and the form(s) needed. |
| Convert the Value | Convert the value(s). Show your calculation(s). |
| Check the Equivalents | Check that each equivalent represents the same amount. |
| Write the Answer | Write the requested equivalents, or the values in the requested order. |

## Slide 1 — Worked demo

Instruction: **Follow each step down your column.**

| Row | Start | Build | Confidence |
| --- | --- | --- | --- |
| The Full Question | Write 1/4 as a decimal and a percentage. | Write 7/20 as a decimal and a percentage. | Put 3/5, 0.58 and 62% in increasing order. |
| Identify the Value | 1/4 means 1 ÷ 4. | 7/20 means 7 ÷ 20. | Use the same form to compare all three. |
| Convert the Value | 1 ÷ 4 = 0.25; 0.25 × 100 = 25%. | 7/20 = 35/100 = 0.35 = 35%. | 3/5 = 0.60; 62% = 0.62. Compare 0.60, 0.58, 0.62. |
| Check the Equivalents | 4 × 0.25 = 1; four quarters make 100%. | 35% lies between 25% and 50%, as does 7/20. | 0.58 < 0.60 < 0.62. |
| Write the Answer | 0.25 and 25%. | 0.35 and 35%. | 0.58, 3/5, 62%. |

## Slide 2 — Step-by-step practice 1

Instruction: **Complete each step in your booklet or webapp.** Use the row prompts above.

| --- | --- | --- |
| Write 3/4 as a decimal and a percentage. | Write 13/20 as a decimal and a percentage. | Put 0.7, 2/3 and 68% in increasing order. |

Teacher working:

- T1: 3 ÷ 4 = 0.75; ×100 = **75%**.
- T2: 13/20 = 65/100 = **0.65 = 65%**.
- T3: 2/3 = 0.666…; 68% = 0.68; **2/3, 68%, 0.7**. Do not round 2/3 to 0.7.

## Checks and review points

- Keep trailing zeros where they aid comparison (0.60), while accepting equivalent decimal forms.
- Ask for increasing order explicitly. Teacher answers use the original forms, not just converted decimals.
- Fractions in independent conversion questions have terminating decimals. No rounding is needed.

- Seven slides; 72 distinct independent questions, plus the worked demo and two practice grids.
- Keep these exact values when creating slides. Recheck readability before publishing.
- The proposed challenge progression, calculator policy and row wording require user review.
