# M10 — Solving equations

**Status: Draft — awaiting review. Not approved for PowerPoint.**

## Scope

Practise the algebraic method with equations already supplied. Include subtraction and negative constants without introducing quadratic equations or algebraic fractions.

Challenge progression: one-step → two-step → brackets and unknowns on both sides.

Calculator proposal: no calculator.

## Row labels and practice prompts

Use these exact labels and prompts on both step-by-step practice slides. Repeat the same prompt across columns unless a genuine difference in the task requires a change.

| Row label | Student prompt |
| --- | --- |
| Simplify the Equation | Expand brackets if needed. Write the equation clearly. |
| Use Inverse Operations | Apply the same operation to both sides. Collect the unknown terms when needed. |
| Find the Unknown | Complete the calculation to find the unknown. |
| Check by Substitution | Substitute your value into the original equation. Check that both sides are equal. |

## Slide 1 — Worked demo

Instruction: **Follow each step down your column.**

| Row | Thread 1: Guided | Thread 2: Core | Thread 3: Depth |
| --- | --- | --- | --- |
| The Full Question | Solve x + 7 = 19. | Solve 3x + 5 = 26. | Solve 4(x + 2) = 2x + 18. |
| Simplify the Equation | No brackets to expand: x + 7 = 19. | No brackets to expand: 3x + 5 = 26. | Expand: 4x + 8 = 2x + 18. |
| Use Inverse Operations | Subtract 7 from both sides. | Subtract 5: 3x = 21. | Subtract 2x, then 8: 2x = 10. |
| Find the Unknown | x = 19 − 7 = 12. | Divide both sides by 3: x = 7. | Divide both sides by 2: x = 5. |
| Check by Substitution | 12 + 7 = 19. So x = 12. | 3 × 7 + 5 = 26. So x = 7. | 4(5+2)=28; 2×5+18=28. So x = 5. |

### Diagram / layout specification

Use editable aligned equations. Put each operation beside the equation and apply it to both sides. The Depth demo shows 4x+8=2x+18, then 2x+8=18, then 2x=10, then x=5. Use a balance diagram only if it helps; no decorative diagram is required.

Instruction: **Complete each step in your booklet or webapp.** Use the row prompts above.

| Solve x − 8 = 15. | Solve 5x + 7 = 42. | Solve 3(x + 4) = x + 26. |

Teacher working:

- T1: Add 8: **x=23**. Check 23−8=15.
- T2: Subtract 7: 5x=35; divide by 5: **x=7**. Check 35+7=42.
- T3: 3x+12=x+26; 2x=14; **x=7**. Both sides 33.

## Checks and review points

- “Move it across and change the sign” is not the explanation: show the same operation on both sides.
- Check by substitution into the original equation, particularly when brackets are present.
- Every independent equation has exactly one integer solution.
- Some Guided equations contain a negative constant; review whether this is appropriate for the lowest thread.

- Seven slides; 72 distinct independent questions, plus the worked demo and two practice grids.
- Keep these exact values when creating slides. Recheck readability before publishing.
- The proposed challenge progression, calculator policy and row wording require user review.
