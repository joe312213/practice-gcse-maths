### Method, errors and checks

### Worked method continuation (page B if needed)

Show the full original question above each column. All steps for one question stay together.

**Thread 1: Guided**

- **Keywords & Calculation:** 42 equal packs, each containing 15 pens: multiply.
- **Written Method:** Editable lattice 42 × 15: cell rows 04, 02 / 20, 10. Diagonals from bottom right: 0 + carry 0 = 0: write 0; 3 + carry 0 = 3: write 3; 6 + carry 0 = 6: write 6; 0 + carry 0 = 0: write 0. Answer 630.
- **Ballpark Check & Math:** 40 × 15 = 600; 630 is close.
- **Final Answer:** 630 pens.

**Thread 2: Core**

- **Keywords & Calculation:** Find the number of full groups of six apples: divide and count only complete bags.
- **Written Method:** Editable bus stop 215 ÷ 6: 2 ÷ 6 = 0 r 2; 21 ÷ 6 = 3 r 3; 35 ÷ 6 = 5 r 5.
- **Ballpark Check & Math:** 35 × 6 + 5 = 215; estimate 210 ÷ 6 = 35.
- **Final Answer:** 35 full bags.

**Thread 3: Depth**

- **Keywords & Calculation:** Hourly charge × hours, then add the one-off paint charge.
- **Written Method:** Editable lattice 18 × 32: cell rows 03, 24 / 02, 16. Diagonals from bottom right: 6 + carry 0 = 6: write 6; 7 + carry 0 = 7: write 7; 5 + carry 0 = 5: write 5; 0 + carry 0 = 0: write 0. Answer 576.
- **Written Method (finish):** 576 + 120: units 6 + 0 = 6; tens 7 + 2 = 9; hundreds 5 + 1 = 6. Total 696.
- **Ballpark Check & Math:** 20 × 30 + 120 = £720, close to £696.
- **Final Answer:** £696.

### Method, errors and checks

| Label | Thread 1: Guided | Thread 2: Core | Thread 3: Depth |
| --- | --- | --- | --- |
| Method | Q1: 168 ÷ 7 = 24 students in each group. | Q1: 16 × 27 = £432 wages. | Q1: 157 ÷ 8 = 19 r 5; 20 vans. 20 × 45 = £900. |
| If you got… | Q1: 1,176: check whether you used 168 × 7 = 1,176. Sharing a fixed total needs division. | Q1: £320: check whether you calculated only 16 × 20 = 320. Include 16 × 7 = 112. | Q1: £855: check whether you used 19 × 45 = 855. Nineteen vans have only 152 seats; hire 20. |
| Check | 140 ÷ 7 = 20; exact check 24 × 7 = 168. | 16 × 30 = £480; subtract 3 × £16 = £48 to get £432. | 160 ÷ 8 × 45 = £900; 20 × 8 = 160 seats. |

### Worked method continuation (page B if needed)

Show the full original question above each column. All steps for one question stay together.

**Thread 1: Guided**

- **Keywords & Calculation:** Share 168 equally among seven groups: divide.
- **Written Method:** Editable bus stop 168 ÷ 7: 1 ÷ 7 = 0 r 1; 16 ÷ 7 = 2 r 2; 28 ÷ 7 = 4 r 0.
- **Ballpark Check & Math:** 140 ÷ 7 = 20; exact check 24 × 7 = 168.
- **Final Answer:** 24 students per group.

**Thread 2: Core**

- **Keywords & Calculation:** Hourly pay × hours: multiply.
- **Written Method:** Editable lattice 16 × 27: cell rows 02, 12 / 07, 42. Diagonals from bottom right: 2 + carry 0 = 2: write 2; 13 + carry 0 = 13: write 3, carry 1; 3 + carry 1 = 4: write 4; 0 + carry 0 = 0: write 0. Answer 432.
- **Ballpark Check & Math:** 16 × 30 = £480; subtract 3 × £16 = £48 to get £432.
- **Final Answer:** £432.

**Thread 3: Depth**

- **Keywords & Calculation:** Find vans needed for all passengers; round up before multiplying by the price per van.
- **Written Method:** Editable bus stop 157 ÷ 8: 1 ÷ 8 = 0 r 1; 15 ÷ 8 = 1 r 7; 77 ÷ 8 = 9 r 5.
- **Interpret before multiplying:** 19 r 5 means 19 vans leave five passengers; use 20 vans.
- **Written Method:** Editable lattice 20 × 45: cell rows 08, 00 / 10, 00. Diagonals from bottom right: 0 + carry 0 = 0: write 0; 0 + carry 0 = 0: write 0; 9 + carry 0 = 9: write 9; 0 + carry 0 = 0: write 0. Answer 900.
- **Ballpark Check & Math:** 160 ÷ 8 × 45 = £900; 20 × 8 = 160 seats.
- **Final Answer:** £900.
