# M01 — Lattice multiplication: website specification

Current website behaviour; historical authored teaching sources and question IDs are preserved. See the [teaching index](../../docs/INDEX.md#teaching-content) for provenance and source material.

## Question wording

Default `questionPrefix`: **Work out the product**. Show it immediately above the question in the answering area. Contextual applications override this with **Solve the problem**. Keep the input label **Answer**; provide required units separately.

## Sensible quick checks

No calculator needed. Round each factor to one significant figure and multiply the rounded values mentally; compare the scale with the exact answer. For example, 4,312 × 156 is about 4,000 × 200 = 800,000, so 672,672 has a plausible size. This is a ballpark check, not proof or a fixed percentage tolerance. Check the last digit separately where helpful. Do not require the learner to divide a large product to check a non-calculator method.
