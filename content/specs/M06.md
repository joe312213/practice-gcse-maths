## Challenge progression

- Start: percentage amounts, including familiar and fractional percentages with manageable exact answers.
- Build: mix increases/decreases; distinguish the change from the new amount.
- Confidence: calculate percentage change between two amounts, using the original as the whole.

Vary contexts and quantities. Values support exact no-calculator working; never create fractional people. Put required units beside the numeric answer field. Diagnose subtracting the percentage number, stopping at the change, reversing direction, using the new denominator, inverting the ratio and forgetting ×100. Do not confuse percentage change with percentage-point differences.

## Method animation

Identify the original whole as 100%. Amounts: inspect whole ÷100, reveal one percent, inspect scaling, reveal the amount. Changes: calculate the change first; then inspect original plus/minus change and reveal the new amount. Percentage change: reveal the difference, compare with the original denominator, then convert to percent. Do not show the final percentage in the diagram before the calculation reveals it. Name units and the requested quantity explicitly.

## Sensible quick checks

No calculator needed for this bank. Use 10%, 50% or 100% as a mental benchmark and check the direction of a price change. A 25% increase on £80 is one quarter of £80 (£20), so the result is £100. Distinguish the percentage amount from the new total; an increase must finish above the original. Choose friendly estimates for longer multi-step problems.

## Units in displayed working

Label intermediate measured amounts and final answers with their appropriate units; prices use a leading £ (after any negative sign). Keep ratio parts and percentage proportions dimensionless. Students enter only the numeric part in the app; Learn the method reminds them to include units in exam working and answers.


## Common errors — agreed 16 October 2026

Agreed by the user on 16 October 2026 for the [spot-error authoring process](../../docs/SPOT_ERRORS_PROCESS.md). These define accepted misconception coverage with illustrative mistakes; agreement does not itself replace live bank questions.

| ID | Misconception / error | Illustrative mistake and intended repair |
| --- | --- | --- |
| P1 | Treating the percentage number as a quantity with the original units | Calling 25% of £80 “£25”, or adding £25 for a 25% increase. Calculate 25/100 of £80 = £20. |
| P2 | Converting a percentage to a decimal/fraction with the wrong place value | 5% → 0.5 instead of 0.05. The denominator is 100. |
| P3 | Confusing the percentage change amount with the new total | For a 25% increase on £80, correctly find £20 but give £20 as the new price. Add it to £80 to obtain £100. Using 0.25 instead of 1.25 as a multiplier for the new price is the same conceptual family. |
| P4 | Applying a change in the wrong direction | A 25% decrease on £80 gives £100. Subtract £20 to obtain £60; use 0.75 rather than 1.25 if using a multiplier. |
| P5 | Using the new amount as the denominator for percentage change | For £80 → £100, calculate 20/100 × 100 = 20%. Compare with the original £80: 25%. |
| P6 | Using the whole new amount instead of the difference in the numerator | For £80 → £100, calculate 100/80 × 100 and call 125% the increase. £100 is 125% of the original, so the increase is 25%. |
| P7 | Inverting the fraction for percentage change | For £80 → £100, use 80/20 × 100 = 400%. The change goes over the original: 20/80 × 100. |
| P8 | Failing to convert a proportion to a percentage | Correctly calculate 20/80 = 0.25, then label the increase 0.25%. Multiply by 100 to obtain 25%. |

Select the conversion, percentage-amount calculation, change/new-total step or comparison fraction. Distinguish £, proportions and percentages in displayed labels so the error is observable rather than inferred from an unexplained number. Accept decompositions such as 10% + 10% + 5%, fraction methods and valid multipliers. Keep Start to amounts, Build to increases/decreases, and Confidence to percentage change relative to the original. P5–P8 are distinct possible faults at the comparison/conversion stages; do not count a later value caused by an earlier wrong fraction as another error. Reverse percentages, compound change and interest remain outside this topic's current scope.
