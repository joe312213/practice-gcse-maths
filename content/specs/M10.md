# M10 — Solving equations: website specification

Current website behaviour; historical authored teaching sources and question IDs are preserved. See the [teaching index](../../docs/INDEX.md#teaching-content) for provenance and source material.

## Question wording

Default `questionPrefix`: **Solve the equation**. Show it immediately above the question in the answering area. Contextual applications override this with **Solve the problem**. Keep the input label **Answer**; provide required units separately.

## Sensible quick checks

No calculator needed. Substitute the proposed value into the original equation, evaluating the two sides separately with manageable arithmetic. For 4x + 3 = 31 and x = 7, 4 × 7 + 3 = 31. For brackets or an unknown on both sides, retain the original brackets and signs. Equality is an exact check; an estimate alone cannot confirm a solution.
