# M10 — Solving equations: website specification

Current website behaviour; historical authored teaching sources and question IDs are preserved. See the [teaching index](../../docs/INDEX.md#teaching-content) for provenance and source material.

## Question wording

Default `questionPrefix`: **Solve the equation**. Show it immediately above the question in the answering area. Contextual applications override this with **Solve the problem**. Keep the input label **Answer**; provide required units separately.

## Sensible quick checks

No calculator needed. Substitute the proposed value into the original equation, evaluating the two sides separately with manageable arithmetic. For 4x + 3 = 31 and x = 7, 4 × 7 + 3 = 31. For brackets or an unknown on both sides, retain the original brackets and signs. Equality is an exact check; an estimate alone cannot confirm a solution.


## Common errors — agreed 16 October 2026

Agreed by the user on 16 October 2026 for the [spot-error authoring process](../../docs/SPOT_ERRORS_PROCESS.md). These define accepted misconception coverage with illustrative mistakes; agreement does not itself replace live bank questions.

| ID | Misconception / error | Illustrative mistake and intended repair |
| --- | --- | --- |
| E1 | Claiming a term has been undone using the wrong inverse | x + 5 = 12 → x = 17. Subtract 5 to isolate x, giving 7. Simply adding 5 to both sides and retaining all terms is valid, even if inefficient. |
| E2 | Breaking equality by changing only one side or applying different operations | Subtract 5 on the left but add 5 on the right of 3x + 5 = 20. Apply the same operation to both sides. |
| E3 | Treating a coefficient as an added number | 4x = 28 → x = 24. Four multiplies x; divide both sides by 4 to obtain 7. |
| E4 | Dividing only some terms on a side | 6x + 8 = 20 → 3x + 8 = 10. Dividing by 2 must give 3x + 4 = 10. |
| E5 | Expanding brackets incompletely or mishandling a sign within them | 3(x + 4) → 3x + 4, or 2(x − 3) → 2x + 6. Correct expansions are 3x + 12 and 2x − 6; use one clearly identified fault per authored example. |
| E6 | Combining unlike terms or losing the variable when collecting like terms | 2x + 3 → 5x, or 5x − 2x → 3. Unlike terms stay separate; 5x − 2x = 3x. |
| E7 | Arithmetic/sign slip within an otherwise valid balancing step | For 3x + 5 = 20, correctly choose −5 on both sides but evaluate 20 − 5 as 25. The choice is valid; the calculation should give 3x = 15. |
| E8 | Checking against the wrong equation or substituting incorrectly | Checking x = 7 in 4x + 3 = 31 as 4 + 7 + 3. Substitute into the original equation: 4 × 7 + 3 = 31, evaluating both sides. |

Select a working line and identify the specific mistaken term/calculation through its explanation; operation choice alone is insufficient. Show operations explicitly so E2 and E7 are distinguishable. Errors when handling unknowns on both sides belong to E2/E6/E7 according to what was actually written. Include correct alternative solution paths: dividing first, adding a term to both sides, or choosing the other side for the unknown is not inherently wrong. A later wrong result derived consistently from an earlier fault is not another independent mistake. E8 applies only where checking is shown, and must not mislabel a mathematically equivalent check as invalid. Keep one-/two-step work before brackets and unknowns on both sides.
