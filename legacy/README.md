# Legacy teaching resources

Saved decks, companion HTML answers and assets were moved here on 3 October 2026 without regeneration. The website is primary. These are historical resources, primarily examples and inspiration for level, style and teaching approach. Reviewed website content takes precedence for implemented topics. Each additional topic’s questions, hints and feedback will be reviewed and refined during website implementation; exact reproduction of a deck is not the acceptance criterion. See the [current content guidance](../website/README.md#current-content-and-historical-references).

- [Original draft](initial_draft_GCSE_Maths_Resit_Starter_Grid.pptx)
- [Topic resources](topics/) — individual decks, answers and original README notes
- [Answer styles](styles/answers.css)

The current application JSON banks are authoritative and maintained directly. Optional reference scripts under `scripts/prepare_web_*.py` reconstruct earlier content into fresh temporary directories only, with no option to replace current banks, catalogues or audit files. The arithmetic reference tool reads saved assessment/answer examples; the equation tool reads historical JSON only. These candidates are not a source of truth for implemented topics. Old slide generators remain historical tooling under `scripts/`; their old paths are not supported after relocation. Do not run or repair them unless slide work is explicitly requested. Original topic README build commands describe the old workflow, not current instructions.

Authored content remains in `content/`. See the [document map](../docs/INDEX.md) for teaching specifications and historical slide notes. Git retains old versions; do not create another backup stack.
