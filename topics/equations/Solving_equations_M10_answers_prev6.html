M10-SE — Spot the errors

Start

Q1 — x + 8 = 19

Shown incorrect working

Answer: x = 11

Method / first error: Adding 8 does not undo +8. Subtract 8 from both sides: x = 11.

Correct working

Check: 11 + 8 = 19.

Q2 — x − 5 = 8

Shown incorrect working

Answer: x = 13

Method / first error: Undo −5 by adding 5 to both sides: x = 13.

Correct working

Check: 13 − 5 = 8.

Q3 — 6x = 24

Shown incorrect working

Answer: x = 4

Method / first error: 6x means 6 times x. Divide both sides by 6: x = 4.

Correct working

Check: 6 × 4 = 24.

Build

Q1 — 3x + 6 = 30

Shown incorrect working

Answer: x = 8

Method / first error: The operations differ across the line. Subtract 6 from both sides: 3x = 24, so x = 8.

Correct working

Check: 3 × 8 + 6 = 30.

Q2 — 4x − 8 = 16

Shown incorrect working

Answer: x = 6

Method / first error: Add 8 to both sides: 4x = 24, then x = 6.

Correct working

Check: 4 × 6 − 8 = 16.

Q3 — 5x + 10 = 45

Shown incorrect working

Answer: x = 7

Method / first error: The entire left side must be divided: x + 2 = 9, so x = 7. Alternatively subtract 10 first.

Correct working

Check: 5 × 7 + 10 = 45.

Confidence

Q1 — 2(x + 5) = 30

Shown incorrect working

Answer: x = 10

Method / first error: Multiply both bracket terms by 2: 2x + 10 = 30. A shorter route is divide both sides by 2 first: x + 5 = 15, then x = 10.

Correct working

Check: 2 × (10 + 5) = 30.

Q2 — 4x + 3 = 2x + 33

Shown incorrect working

Answer: x = 15

Method / first error: Subtract 2x from both sides: 2x + 3 = 33; 2x = 30; x = 15.

Correct working

Check: 4 × 15 + 3 = 2 × 15 + 33 = 63.

Q3 — 3(x − 4) = x − 16

Shown incorrect working

Answer: x = -2

Method / first error: Expand the whole bracket: 3x − 12 = x − 16. Subtract x, then add 12: 2x = −4, so x = −2.

Correct working

Check: 3 × (−2 − 4) = −2 − 16 = −18.
