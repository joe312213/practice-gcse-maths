About Maths practice

Author and purpose

Created by Joe Hudson to help Foundation GCSE Maths students practise accurate methods and build confidence through short, regular activities.

Related Apps

The theme palettes, controls and puzzles are adapted from T-Level starters site. Its source code also informed the approach to practice, feedback and saved progress.

How it is developed

This is an agent-augmented development project: I develop specifications and harness related processes, UI design, review and update generated code, set the teaching direction, create and review a sample of teaching content. The AI helps with planning, reviewing specs and mostly takes care of code implementation with close human-in-the-loop feedback and review, content preparation and testing. Automated maths and behaviour tests are used alongside manual browser and visual checks.

The site is still being developed. Checks support review; they do not imply that every topic or feature is finished. There are currently many missing topics and planned features, hopefully coming soon. Requests and suggestions are welcome.

Progress tracking feature

Names and progress are stored in this browser on this device. They are not online accounts and are not synchronised across devices.
