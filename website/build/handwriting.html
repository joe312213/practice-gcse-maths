Handwriting comparison

Compare the extended Pacifico Maths with the original 16 stroke fonts. Replay writes along the supplied pen paths. Pacifico Maths is used for written working in the teaching animations.

Try the same example in each font

Dashed boxes contain ordinary text for missing characters: they are not available pen strokes. The exact Unicode minus (−) is checked separately from the keyboard hyphen (-).

All samples use a 1.5px pen. Compare x with ×, 1 with l, and 0 with O. Serif and bold fonts may retrace strokes; their stored order is not necessarily how a teacher would write.

Fractions, powers, roots with a bar and vectors also need mathematical layout. A glyph alone does not supply that layout. Reduced-motion settings show the completed example immediately.
