FAQ & troubleshooting

How do I save my progress?

Your answers save in this browser as you work. To keep a copy in OneDrive, select Save to OneDrive and choose your OneDrive folder. We’ll put your progress in the Maths folder and update it as you finish pages or change stages.

Using another computer?

Let OneDrive finish syncing first. On Progress, select Open progress file and choose your saved file from the Maths folder. Use one computer at a time. Your results travel with you; unfinished pages and drawings stay in the original browser.

Which copy of my progress should I use?

If your OneDrive file has newer results, we’ll ask whether to use them. This replaces the progress on this browser. If you’re unsure, keep your browser progress and download a backup before choosing.

Having trouble saving or opening a file?

Your browser progress stays here if a save fails. Try Save progress file on Progress and allow folder access if asked. If you’re using an app’s preview window, download a backup first, then open the site in Chrome or Edge and import it there.

To restore a backup, choose the Maths progress file ending in .json. A file that cannot be opened won’t replace your progress. Check any save warning before closing the tab: closing too quickly can interrupt a save.

How do timers work?

The timer is optional. Use + or − to choose your time, then Start. You can pause or reset it. A soft chime sounds when time is up, but you can keep working. Timed Practice sets have their own time limit.

What do the progress bars show?

They show how you’ve done recently at each level. Select a segment for more detail. Answers completed with help don’t raise your score. Weekly figures cover the whole week, so they may look different. A dash means there isn’t enough information yet.

How is practice time counted?

Time counts while you’re learning or practising. It pauses when you switch tabs or stop interacting for two minutes.

When is a recommended set complete?

Finish all four pages. Your answers don’t all need to be correct.

Still need help?

Try refreshing the page. If the problem continues, use Report an issue below. You can check the report before sending it.
